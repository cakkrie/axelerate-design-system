# Axelerate — website UI kit

**Demonstrative, not a recreation.** No product source (codebase, Figma, screenshots) was provided, so this landing page illustrates how the brand system composes into a full surface. Replace with real product recreations when sources arrive.

`index.html` — invite-only marketing landing. Interactive: nav/hero/pricing CTAs open the "Request an invite" dialog (email validation → success toast), "Who it's for" tabs, Monthly/Yearly pricing toggle.

Composed entirely from the design-system bundle: Button, IconButton, Input, Select, Checkbox, Tabs, Card, Badge, Dialog, Toast. Icons are Lucide paths (zap, users, trending-up, arrow-right, check).
